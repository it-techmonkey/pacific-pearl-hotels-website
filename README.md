# Pacific Pearl Hotels Website

A production-ready, multi-page Next.js site for Pacific Pearl Hotels.

## Tech Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Framer Motion
- ESLint + Prettier

## Local Development

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## Build

```bash
npm run build
```

## Lint

```bash
npm run lint
```

## Format

```bash
npm run format
```

## Notes

- Assets are stored in public/assets and referenced with next/image.
- Content is managed through structured data files in src/data.
